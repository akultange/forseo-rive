@rive-app/canvas
import { Rive } from '@rive-app/canvas';

const forseo = new Rive({
  src: 'forseo.riv',
  canvas: document.querySelector('#forseo'),
  artboard: 'Forseo',
  stateMachines: 'Forseo',
  autoplay: true,
  onLoad: () => forseo.resizeDrawingSurfaceToCanvas(),
});
const input = (name) =>
  forseo.stateMachineInputs('Forseo').find((i) => i.name === name);

input('state').value = 2;      // thinking
input('happy').fire();          // one-shot reaction
input('lipsync').value = true;
input('talk').value = volume * 100; // each frame while speaking
input('follow').value = true;
input('lookX').value = 40;    // -100 left … 100 right
  • Transitions blend from any state to any other in about 0.4 s, and a reaction can interrupt a transition, so nothing waits on a previous animation.
  • Blinks come from a separate layer with random timing, so the idle never looks like a loop.
  • The final delivery is the Rive editor file plus the exported .riv. This spec file is watermarked.
